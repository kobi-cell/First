מסמך זה כולל:
- ארכיטקטורת יעד דינמית
- מנגנון אוטומציה תחת אישור משתמש (Human-in-the-Loop)
- מיפוי תהליכים לפי תחומים (גבייה, מכירות, שיווק, תפעול, הנהלה)
- תוכנית עבודה בשלבים
- מדד אוטומציה (Automation Index) ו-KPI לתיאום ציפיות
- תוכנית אופרטיבית לצמצום מספר מערכות בתהליך
- הגדרה פרקטית של Workbench (מערכת + מתודולוגיה) והטמעה מדורגת
- דף הנחיות עבודה יומי לצוות הגבייה
